# PMo 数据集流程复杂度统计与分档

## 口径

- 数据源：`pmo-dataset/pme/*.json`，并与 `pmo-dataset/bpmn/*.bpmn` 逐流程交叉校验。
- Task 数：PME 的 `tasks` 数组长度。
- 网关数：PME 的 `gateways` 数组长度，包含 Exclusive、Parallel、Inclusive、Event-based 和 Complex Gateway。
- 校验结果：55 个流程的 Task 数和网关数均与标准 BPMN XML 直接计数一致。

## 复杂度分档

采用结构复杂度分数：

`ComplexityScore = Tasks + 2 × Gateways`

网关会引入分支、汇合、并行同步或事件选择，因此按 Task 的 2 倍计权。阈值使用本数据集分数的约三分位点，以形成规模相对均衡的三档：

| 档位 | 分数范围 | 流程数 | 流程编号 |
|---|---:|---:|---|
| 低 | ≤ 24 | 19 | 01, 05, 08, 13, 14, 15, 19, 21, 22, 23, 24, 35, 42, 49, 50, 51, 52, 53, 54 |
| 中 | 25–33 | 20 | 02, 03, 04, 06, 09, 10, 12, 20, 26, 30, 33, 34, 37, 38, 40, 41, 43, 45, 46, 48 |
| 高 | ≥ 34 | 16 | 07, 11, 16, 17, 18, 25, 27, 28, 29, 31, 32, 36, 39, 44, 47, 55 |

完整逐流程计数、网关类型分解、分数和档位见 `pmo-complexity-counts.csv`。

## 解释边界

该分档衡量的是模型结构规模，适合抽样实验和分层评估。它暂未额外计入回环、嵌套深度、泳道、消息流、事件类型和自然语言描述难度；若后续需要更严格的“语义与控制流复杂度”分档，可在当前分数上加入这些因素。
